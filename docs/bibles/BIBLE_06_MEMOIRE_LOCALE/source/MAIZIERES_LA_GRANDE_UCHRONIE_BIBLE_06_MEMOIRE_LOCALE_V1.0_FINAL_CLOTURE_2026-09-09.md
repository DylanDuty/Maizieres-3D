## Principes de sécurité documentaire

1. **Mémoire ≠ preuve juridique ou cadastrale.**
2. Une anecdote peut être authentique dans son sens sans être littéralement vérifiable dans chaque détail.
3. Un hommage municipal renseigne ce que la communauté choisit de retenir ; il ne constitue pas un audit neutre de toute une vie.
4. Une carte postale prouve ce qu'elle montre, pas la fréquence d'une pratique.
5. Une reconstitution de 2014 ne doit jamais être datée de 1944.
6. Un patronyme identique ne prouve aucune filiation.
7. Une voix manquante doit être recherchée, jamais inventée.
8. Les souvenirs doivent rester datés par génération et par lieu.

# 3. HIÉRARCHIE DES SOURCES DE MÉMOIRE

## M1 — Témoignage direct publié et nominatif
Exemple :
- entretien avec Michel Payen dans le bulletin municipal de décembre 2021.

Valeur :
très forte pour :
- expérience vécue ;
- gestes ;
- impressions ;
- organisation quotidienne ;
- noms utilisés dans le souvenir.

Limite :
le témoignage peut comporter :
- approximation de date ;
- confusion de lieu ;
- reconstruction tardive.

## M2 — Portrait biographique local
Exemples :
- Jacques Iost ;
- Madeleine Renault ;
- Michel Bourcier.

Valeur :
forte pour :
- trajectoire ;
- engagement ;
- mémoire collective d'une personne.

## M3 — Mémoire iconographique identifiée
Exemples :
- photo de classe 1958-1959 ;
- compagnie de sapeurs-pompiers vers 1960 ;
- L'Étoile en 1936 ;
- cartes postales de la gare et de l'avenue de la Gare.

Valeur :
forte pour :
- visages ;
- vêtements ;
- densité humaine ;
- formes de sociabilité ;
- environnement.

## M4 — Tradition locale publiée
Exemple :
- baptême des Bédouins.

Valeur :
forte comme tradition.
Faible pour une datation ou fréquence exacte si la source ne le dit pas.

## M5 — Mémoire patrimoniale reconstruite
Exemples :
- récits du Gué de la Chapelle ;
- « Mare aux Canards » ;
- mémoire des anciens lieux ;
- transmission des cloches.

## M6 — Tradition non publiée / témoignage non identifié
À conserver seulement comme piste tant qu'un témoin ou une source n'est pas identifié.

# 4. RÈGLE ABSOLUE — MÉMOIRE ≠ PREUVE BRUTE

Lorsqu'un témoin dit :

> « à cet endroit se trouvait X »

BIBLE_06 peut enregistrer :
**« X est ainsi localisé dans la mémoire de ce témoin. »**

Elle ne doit pas automatiquement convertir cela en :
**« X se trouvait juridiquement et cadastralement exactement ici. »**

Les autres Bibles servent à recouper :
- BIBLE_01 pour le lieu ;
- BIBLE_02 pour les événements ;
- BIBLE_05 pour le commerce / exploitant.

# 6. MICHEL PAYEN — LE BOMBARDEMENT DE 1943 COMME SOUVENIR D'ENFANT

Michel Payen raconte qu'il avait presque six ans lorsque son père meurt en :
**1943**.

Son père était allé chez le :
**maréchal-ferrant**

pour faire ferrer un cheval.

Michel Payen identifie le site au moment de l'entretien comme l'emplacement devenu :
**A Vos Couverts**.

Il raconte :
- un bombardement allié visant le camp allemand ;
- une bombe tombée chez le maréchal-ferrant ;
- la mort de son père ;
- la destruction, le même jour, de la maison de ses grands-parents ;
- la survie des grands-parents.

## Importance

C'est une mémoire familiale extrêmement forte :
- lieu ;
- victime ;
- cheval ;
- artisan ;
- bombardement ;
- destruction de la maison familiale.

## Règle

Le témoignage ne suffit pas à identifier juridiquement le maréchal-ferrant.
BIBLE_05 conserve Jean-Baptiste Pastor comme candidat non prouvé.
